## 1. Задача №111156. Сортировка выбором

Дан список целых чисел. Выведите все элементы этого списка в порядке невозрастания значений.

Решите задачу при помощи алгоритма сортировки выбором. Решение оформите в виде функции `SelectionSort(A)`.

В сортировке выбором на каждом шаге находится наибольший элемент неотсортированной части списка и ставится на очередную позицию.

### Пример

**Входные данные**

```text
1 4 2 3 4
```

**Выходные данные**

```text
4 4 3 2 1
```


**Входные данные**

## 7. Задача №325. Сортировка точек

Выведите все исходные точки в порядке возрастания их расстояний от начала координат.

Исходные данные сохраняются как объекты `Point`. В Python для этого используется класс `Point` с полями `x` и `y`.

### Входные данные

Сначала задано количество точек `n`. Далее идут `n` строк, каждая из которых содержит две целые координаты точки. `n ≤ 100`, координаты по модулю не превосходят `10^3`.

### Выходные данные

Выведите координаты точек в порядке возрастания расстояния от начала координат. Количество точек выводить не надо.

### Пример

**Входные данные**

```text
2
1 2
2 3
```

**Выходные данные**

```text
1 2
2 3
```
