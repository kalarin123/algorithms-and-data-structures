## 1. Задача №111156. Сортировка выбором

Дан список целых чисел. Выведите все элементы этого списка в порядке невозрастания значений. Выведите новый список на экран.

Решите задачу при помощи алгоритма сортировки выбором. Решение оформите в виде функции `SelectionSort(A)`.

В алгоритме сортировки выбором находится наибольший элемент списка и ставится на первое место, затем наибольший элемент из оставшихся ставится на второе место и т. д.

### Пример

**Входные данные**

```text
1 4 2 3 4
```

**Выходные данные**

```text
4 4 3 2 1
```

## 2. Задача №111157. Сортировка вставкой

Дан список целых чисел. Отсортируйте его в порядке неубывания значений. Выведите полученный список на экран.

Решите задачу при помощи алгоритма сортировки вставкой. Решение оформите в виде функции `InsertionSort(A)`.

В этой задаче нельзя пользоваться дополнительным списком, операциями удаления и вставки элементов.

В каждый момент начальная часть массива уже отсортирована. Очередной элемент `A[i]` добавляется в правильную позицию внутри этой части, а элементы сдвигаются вправо.

### Пример

**Входные данные**

```text
1 4 2 3 4
```

**Выходные данные**

```text
1 2 3 4 4
```
