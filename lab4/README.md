## 1. Задача №755. Хипуй!!!

Реализовать структуру `Heap` для хранения целых чисел с двумя операциями: `Insert(k)` — добавить число, `Extract` — извлечь и удалить **максимум**. Использовать готовые структуры данных запрещено.

### Входные данные

В первой строке `N` (`1 ≤ N ≤ 100000`). Затем `N` команд: `0 k`, где `1 ≤ k ≤ 1000000`, — добавить число; `1` — извлечь максимум. При извлечении в куче обязательно есть элемент.

### Выходные данные

Для каждой команды извлечения вывести результат в новой строке.

### Пример

**Входные данные**

```text
2
0 10000
1
```

**Выходные данные**

```text
10000
```

### Алгоритм

Храним двоичную max-кучу в массиве. При добавлении выполняем подъём элемента, при извлечении — просеивание вниз. Сложность каждой операции — `O(log N)`.

**Решение:** [`lab4_1-4.py`](lab4_1-4.py)

## 2. Задача №754. Пирамидальная сортировка

Отсортировать массив **в порядке неубывания** с помощью пирамидальной сортировки. Готовые сортировки не используются.

### Входные данные

Число элементов `N ≤ 10^5`, затем `N` целых чисел, по модулю не превосходящих `10^9`.

### Выходные данные

Элементы массива по неубыванию, через пробел.

### Пример работы

**Входные данные**

```text
5
4 1 3 2 5
```

**Выходные данные**

```text
1 2 3 4 5
```

### Алгоритм

Сначала строим max-кучу. Затем меняем корень с последним элементом неотсортированной части и восстанавливаем кучу. Время — `O(N log N)`, дополнительная память алгоритма сортировки — `O(1)`.

**Решение:** [`lab4_2-4.py`](lab4_2-4.py)

## 3. Задача №3493. Пирамида (минимум)

Обработать команды `CLEAR` — очистка, `ADD n` — добавление числа, `EXTRACT` — извлечение и удаление **минимума**. Если куча пуста, вывести `CANNOT`. Требуется собственная реализация на C++.

### Входные данные

Команды по одной в строке до конца файла. Всего не больше 200000 запросов.

### Выходные данные

Для каждой команды `EXTRACT` вывести найденный минимум либо `CANNOT`. Команды `CLEAR` и `ADD` ничего не выводят.

### Пример работы

**Входные данные**

```text
ADD 7
ADD 2
EXTRACT
CLEAR
EXTRACT
```

**Выходные данные**

```text
2
CANNOT
```

### Алгоритм

Реализован класс `MinHeap`, который хранит числа в массиве. Добавление и извлечение с просеиванием работают за `O(log N)`.

**Решение:** [`lab4_3-4.cpp`](lab4_3-4.cpp)

## 4. Задача №3492. Пирамида (максимум)

Обрабатывать `CLEAR`, `ADD n` и `EXTRACT`. Последняя команда извлекает **максимальный** элемент либо выводит `CANNOT`, если куча пуста. По условию задачу требуется решить двумя способами: с `priority_queue` и самостоятельно.

### Входные данные

Последовательность команд, каждая в отдельной строке. Не более 200000 запросов.

### Выходные данные

Каждый результат `EXTRACT` в отдельной строке.

### Пример

**Входные данные**

```text
ADD 192168812
ADD 125
ADD 321
EXTRACT
EXTRACT
CLEAR
ADD 7
ADD 555
EXTRACT
EXTRACT
EXTRACT
```

**Выходные данные**

```text
192168812
321
555
7
CANNOT
```

### Алгоритм

Первая программа использует контейнер `std::priority_queue`. Вторая — собственный класс `MaxHeap` с просеиванием. Вставка и извлечение занимают `O(log N)`.

**Решения:** [`lab4_4-4.cpp`](lab4_4-4.cpp) — стандартная реализация; [`lab4_4-5.cpp`](lab4_4-5.cpp) — собственная.

## 5. Задача №746. Коммерческий калькулятор

Нужно вычислить сумму `N` натуральных чисел, заплатив **минимальную сумму денег**. Стоимость каждой операции сложения — 5% от суммы двух операндов. Стоимость всех сложений зависит от порядка действий.

### Входные данные

`N` (`2 ≤ N ≤ 10^5`); затем `N` натуральных чисел, каждое не больше 10000.

### Выходные данные

Минимальную стоимость, округлённую до двух знаков после десятичной точки.

### Пример 1

**Входные данные**

```text
4
10 11 12 13
```

**Выходные данные**

```text
4.60
```

### Пример 2

**Входные данные**

```text
2
1 1
```

**Выходные данные**

```text
0.10
```

### Алгоритм

Каждый раз складываем два наименьших числа, учитываем стоимость операции и возвращаем сумму в min-кучу. Время — `O(N log N)`.

**Решение:** [`lab4_5-4.py`](lab4_5-4.py)

## 6. Задача №1755. Таможня

Есть грузы с временем прибытия и длительностью обработки. Каждый аппарат может обрабатывать только один груз одновременно. Найти **минимальное число аппаратов**, чтобы обработка каждого груза начиналась сразу при прибытии.

### Входные данные

`N` (`0 ≤ N ≤ 50000`). Затем `N` строк с целыми числами `Tᵢ` и `Lᵢ` — временем прибытия и временем обработки (`1 ≤ Tᵢ, Lᵢ ≤ 10^6`).

### Выходные данные

Минимальное количество аппаратов.

### Пример 1

**Входные данные**

```text
3
3 2
4 2
5 2
```

**Выходные данные**

```text
2
```

### Пример 2

**Входные данные**

```text
5
13 4
15 1
11 5
12 3
10 3
```

**Выходные данные**

```text
3
```

### Алгоритм

Сортируем грузы по прибытии. В min-куче поддерживаем времена завершения обработок. Перед добавлением груза удаляем завершившиеся обработки. Ответ — максимальный размер кучи. Сложность — `O(N log N)`.

**Решение:** [`lab4_6-4.py`](lab4_6-4.py)

## 7. Задача №3407. Вычислительная ихтиология

В ряд расположены `n` аквариумов. В колонии размера `f` следующая рыбка рождается через `max(1000 − f, 1)` секунд; численность после рождения увеличивается на один. Наблюдатель должен находиться возле нужного аквариума в момент рождения. Переход к соседнему аквариуму занимает одну секунду, изначально наблюдатель стоит у первого аквариума.

Нужно найти момент, когда он впервые не сможет зафиксировать рождение рыбки.

### Входные данные

`n` (`2 ≤ n ≤ 50`), затем `n` строк с численностями колоний `aᵢ` (`1 ≤ aᵢ ≤ 2007`).

### Выходные данные

Одно целое число — момент первого пропущенного рождения.

### Пример

**Входные данные**

```text
3
996
1
994
```

**Выходные данные**

```text
7
```

### Алгоритм

Храним в min-куче ближайшее событие рождения для каждого аквариума. После извлечения события проверяем, успевает ли наблюдатель перейти от предыдущего аквариума, и добавляем следующее событие для данной колонии.

**Решение:** [`lab4_7-4.py`](lab4_7-4.py)
