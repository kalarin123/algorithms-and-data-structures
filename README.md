## Структура лабораторной работы

Каждая работа размещается в отдельной папке:

```text
lab-01/
├── README.md       # условие и ссылка на задание
├── solution.*      # исходный код решения
└── report.pdf      # отчёт, если требуется
```

Если в одной лабораторной несколько задач, для них создаются отдельные файлы или подпапки. Названия папок оформляются последовательно: `lab-01`, `lab-02`, `lab-03` и далее.
