## 1. Задача №55. Стек с защитой от ошибок

Реализовать стек, поддерживающий команды `push n` (добавление), `pop` (удаление последнего), `back` (просмотр последнего), `size`, `clear` и `exit`. `pop` и `back` на пустом стеке должны выдавать `error`. `push` и `clear` выводят `ok`, `exit` — `bye`.

### Входные данные

Последовательность команд, по одной в строке, до команды `exit`.

### Выходные данные

Результат каждой команды в отдельной строке.

### Пример

**Входные данные**

```text
size
push 1
size
push 2
pop
back
clear
exit
```

**Выходные данные**

```text
0
ok
1
ok
2
1
ok
bye
```

### Алгоритм

Класс Stack хранит элементы в списке; добавление и удаление с конца следуют принципу LIFO.

**Решение:** [`lab3_1.py`](lab3_1.py)

## 2. Задача №51. Правильная скобочная последовательность

Определить, является ли последовательность из круглых `()`, квадратных `[]` и фигурных `{}` скобок правильной. Пустая последовательность считается правильной.

### Входные данные

Одна строка, не более 100000 скобок.

### Выходные данные

`yes` для правильной последовательности, иначе `no`.

### Пример

**Входные данные**

```text
()[]
```

**Выходные данные**

```text
yes
```

### Алгоритм

Открывающие скобки кладём в стек. Для каждой закрывающей сравниваем тип с верхней скобкой и удаляем пару. В конце стек должен быть пуст. Время O(n).

**Решение:** [`lab3_2.py`](lab3_2.py)

## 3. Задача №52. Постфиксная запись

Вычислить арифметическое выражение в обратной польской (постфиксной) записи. Поддерживаются операции `+`, `-`, `*`.

### Входные данные

Одна строка с числами и операциями, разделёнными пробелами.

### Выходные данные

Одно целое число — результат вычисления.

### Пример

**Входные данные**

```text
8 9 + 1 7 - *
```

**Выходные данные**

```text
-102
```

### Алгоритм

Операнды складываем в стек. На операции сначала извлекаем правый, затем левый операнд, вычисляем и кладём результат обратно. Время O(n).

**Решение:** [`lab3_3.py`](lab3_3.py)

## 4. Задача №58. Очередь с защитой от ошибок

Реализовать очередь с командами `push n`, `pop`, `front`, `size`, `clear`, `exit`. Очередь работает по принципу FIFO. Для пустой очереди `front` и `pop` возвращают `error`.

### Входные данные

Последовательность команд по одной в строке, до `exit`.

### Выходные данные

Ответ на каждую команду: число, `ok`, `error` или `bye`.

### Пример

**Входные данные**

```text
push 1
front
exit
```

**Выходные данные**

```text
ok
1
bye
```

### Алгоритм

Класс Queue использует два стека: входящий и выходящий. При необходимости переносим элементы из входящего стека в выходящий. Амортизированное время операций O(1).

**Решение:** [`lab3_4.py`](lab3_4.py)

## 6. Задача №756. Минимум на отрезке

По последовательности из N чисел найти минимум для каждого последовательного окна длиной K.

### Входные данные

В первой строке N и K (`1 ≤ N ≤ 150000`, `1 ≤ K ≤ 10000`, `K ≤ N`), затем N целых чисел.

### Выходные данные

N − K + 1 строк — минимум для каждого положения окна.

### Пример

**Входные данные**

```text
7 3
1 3 2 4 5 3 1
```

**Выходные данные**

```text
1
2
2
3
1
```

### Алгоритм

Каждый стек MinStack хранит для вершины текущий минимум. Очередь MinQueue использует два таких стека: её минимум равен минимуму их минимумов. Общая сложность O(N).

**Решение:** [`lab3_6.py`](lab3_6.py)

## 7. Задача №869. Сортировка вагонов

Дан порядок вагонов, едущих к тупику. Можно ли с помощью въезда в тупик и выезда из него выпустить вагоны по возрастанию номеров? Каждый вагон может попасть в тупик не более одного раза.

### Входные данные

N (`1 ≤ N ≤ 100`), далее перестановка из чисел от 1 до N.

### Выходные данные

`YES`, если сортировка возможна, иначе `NO`.

### Пример

**Входные данные**

```text
3
3 2 1
```

**Выходные данные**

```text
YES
```

### Алгоритм

Тупик моделируем стеком: кладём очередной вагон и выпускаем верхние вагоны, пока верхний совпадает со следующим ожидаемым номером. Время O(N).

**Решение:** [`lab3_7.py`](lab3_7.py)

## 8. Задача №112984. Гоблины и шаманы

Обрабатывать запросы `+ i` (гоблин встаёт в конец), `* i` (привилегированный встаёт в середину; при нечётной длине — сразу за центром), `-` (первый гоблин обслуживается и покидает очередь).

### Входные данные

N (`1 ≤ N ≤ 100000`), затем N запросов. По условию при запросе `-` очередь не пуста.

### Выходные данные

Для каждого запроса `-` вывести номер обслуженного гоблина.

### Пример

**Входные данные**

```text
7
+ 1
+ 2
-
+ 3
+ 4
-
-
```

**Выходные данные**

```text
1
2
3
```

### Алгоритм

Поддерживаем две деки left и right; длина левой не меньше длины правой и отличается максимум на единицу. Добавление в конец/середину и удаление из начала — O(1).
